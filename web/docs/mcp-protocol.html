协议版本 2025-06-18。向 /mcp 发送 HTTP POST，保留服务返回的会话 Cookie。每个新会话拥有独立工作簿。

5 个工具

  • workbook_info：名称与工作表
  • read_cell：单个单元格
  • read_range：最多 1000×100 区域
  • write_cell：单元格内容或公式
  • format_range：有限样式属性

先发送 initialize，然后 notifications/initialized。tools/list 返回工具定义，tools/call 执行工具。sheet 为从 0 开始的索引或名称；单元格使用 A1 地址。写入支持撤销，遵守工作表保护。
