# 功能与限制

| 能力 | 基础版范围 |
| --- | --- |
| 单元格、公式、样式、多表 | 本机编辑、计算、撤销重做；公式支持受 IronCalc 实现范围约束 |
| 条件格式、验证、保护 | 支持已实现的标准规则；未知扩展尽量保留 |
| XLSX / XLSM | 导入与导出；不运行 VBA，不承诺第三方扩展语义完全一致 |
| CSV | 当前表显示值，支持 UTF-8 和部分 Excel 常见编码；样式与多表不可携带 |
| UDOC / HTML | UniCell 数据与对象的往返容器；任意第三方 HTML 不一定能无损还原 |
| 图表、透视表、切片器、时间线、SmartArt | 可解析与局部编辑的能力因对象类型而异；其余部分按 OOXML 部件保留 |
| 数据连接 / Power Query | 只实现有限本机数据操作；不是完整 Power Query 或外部数据连接执行器 |
| 字体 / 打印 | 取决于本机字体与浏览器；缺字体时可能替换，分页可能与 Excel 不同 |
| 文件保存 | 本机文件或浏览器下载；不提供云同步、共享编辑和账号恢复 |
| AI / MCP | 用户自配模型与本机工具；5 个 MCP 工具只操作当前 Cookie 会话 |

服务监听回环地址，拒绝非本机 Host 和跨站请求。它面向个人本机使用，不提供多用户公网部署能力。

导入文件最大 64 MiB；解压后的 XLSX 部件有额外大小限制。大表、复杂图形及公式可能占用明显内存与计算时间。

自动化测试证明的是已覆盖用例的行为，不是所有 Excel 文档的完全兼容。对重要文件，请用副本比较导入前后内容、公式、图形和打印效果。
