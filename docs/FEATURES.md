# 功能与限制

[项目概述](../README.zh-CN.md) · [同类产品对照](COMPARISON.zh-CN.md)

| 能力 | 公开本机版范围 |
| --- | --- |
| 单元格、公式、样式、多工作表 | 本机编辑、计算、撤销与重做；公式支持范围受 IronCalc 实现范围约束 |
| 条件格式、数据验证、保护 | 支持已实现的标准规则；未识别的扩展内容尽可能保留 |
| XLSX / XLSM | 导入与导出；不执行 VBA，不保证第三方扩展的语义完全一致 |
| CSV | 内容为当前工作表的显示值；支持 UTF-8 和部分 Excel 常见编码；不保留样式与多工作表 |
| UDOC / HTML | UniCell 数据与对象的往返容器；任意第三方 HTML 不保证无损还原 |
| 图表、数据透视表、切片器、日程表、SmartArt | 可解析与可局部编辑的范围因对象类型而异；其余部分按 OOXML 部件保留 |
| 数据连接 / Power Query | 仅实现有限的本机数据操作；不是完整的 Power Query 或外部数据连接执行器 |
| 字体 / 打印 | 取决于本机字体与浏览器；缺少字体时可能发生字体替换，分页结果可能与 Excel 不同 |
| 文件保存 | 保存为本机文件或通过浏览器下载；不提供云同步、共享编辑和账号恢复 |
| AI / MCP | 使用者自行配置模型与本机工具；5 个 MCP 工具仅操作当前 Cookie 会话 |

服务监听回环地址，拒绝非本机 Host 和跨站请求。本服务面向个人本机使用，不提供多用户公网部署能力。

导入文件最大 64 MiB；解压后的 XLSX 部件另有大小限制。大型工作表、复杂图形及公式可能占用较多内存与计算时间。

自动化测试仅证明已覆盖用例的行为，不代表与所有 Excel 文档完全兼容。对于重要文件，建议使用副本比较导入前后的内容、公式、图形和打印效果。
